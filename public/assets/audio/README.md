# SAFE-SPACE Audio

Letakkan file audio game di folder ini dengan nama berikut:

Music:
- `music/main-theme.mp3`
- `music/story-theme.mp3`
- `music/reflection-theme.mp3`

Sound effect:
- `sfx/click.mp3`
- `sfx/choice.mp3`
- `sfx/back.mp3`
- `sfx/success.mp3`

Jika ingin mengganti nama file, update juga daftar path di `src/utils/AudioAssets.js`.
